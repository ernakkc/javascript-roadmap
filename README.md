## 📖 Overview

This repository contains a complete, structured JavaScript learning roadmap covering everything from fundamental concepts to advanced backend development with Node.js and Express.js. Each module includes theory, examples, and hands-on projects.

## ✨ What You'll Learn

- 🎯 **JavaScript Fundamentals**: Variables, data types, and operators
- 🧠 **Control Flow**: Conditions, loops, and logic
- ⚡ **Functions**: Function declarations, expressions, and arrow functions
- 📦 **Data Structures**: Arrays, objects, and advanced methods
- 💾 **File System**: Reading and writing files with Node.js
- 🔄 **CRUD Operations**: Create, Read, Update, Delete patterns
- 📁 **Modular Code**: ES6 modules and code organization
- 🌐 **Express.js**: Building RESTful APIs
- 🤝 **Promises**: Asynchronous programming
- 🚀 **REST API Standards**: Best practices for API design

## 📚 Course Structure

### 1️⃣ Temel Mantık (Basic Logic)
**Topics**:
- Variables (`let`, `const`, `var`)
- Data types (String, Number, Boolean, null, undefined)
- Basic operators
- Console operations
- Type conversion

**Files**: `1-Temel Mantık/`

### 2️⃣ Koşullar (Conditions)
**Topics**:
- `if`, `else if`, `else` statements
- Ternary operator
- `switch` statements
- Logical operators (`&&`, `||`, `!`)
- Comparison operators

**Files**: `2-Koşullar/`

### 3️⃣ Döngüler (Loops)
**Topics**:
- `for` loops
- `while` loops
- `do...while` loops
- `for...of` and `for...in`
- `break` and `continue`

**Files**: `3- Döngüler/`

### 4️⃣ Fonksiyonlar (Functions)
**Topics**:
- Function declarations
- Function expressions
- Arrow functions
- Parameters and arguments
- Return statements
- Scope and closures

**Files**: `4-Fonksiyonlar/`

### 5️⃣ Array (Arrays)
**Topics**:
- Array creation and manipulation
- Array methods (`push`, `pop`, `shift`, `unshift`)
- Iteration methods (`map`, `filter`, `reduce`)
- `forEach`, `find`, `some`, `every`
- Sorting and searching

**Files**: `5-Array/`

### 6️⃣ Object (Objects)
**Topics**:
- Object literals
- Object properties and methods
- `this` keyword
- Object destructuring
- Object methods (`Object.keys`, `Object.values`, `Object.entries`)

**Files**: `6-Object/`

#### Mini Projects
- **6.1-Mini Proje 1**: First practical application
- **6.2-Mini Proje 2**: Second practical application

### 7️⃣ File System & Persistence
**Topics**:
- Node.js `fs` module
- Reading files (`readFile`, `readFileSync`)
- Writing files (`writeFile`, `writeFileSync`)
- File paths and directories
- JSON file operations

**Files**: `7-File System & Persistence/`

### 8️⃣ CRUD Mantığı (CRUD Logic)
**Topics**:
- Create operations
- Read operations
- Update operations
- Delete operations
- Data validation
- Error handling

**Files**: `8-CRUD Mantığı/`

### 9️⃣ Modulerleşme (Modularization)
**Topics**:
- CommonJS modules (`require`, `module.exports`)
- ES6 modules (`import`, `export`)
- Creating custom modules
- NPM packages
- Package.json

**Files**: `9-Modulerlesme/`

### 🔟 Express.js
**Topics**:
- Setting up Express server
- Routing and middleware
- Request and response objects
- Query parameters and body parsing
- Static file serving
- Template engines

**Files**: `10-Express.js/`

### 1️⃣1️⃣ Promises
**Topics**:

### 1️⃣2️⃣ REST API Standart (REST API Standards)
**Topics**:
- HTTP methods (GET, POST, PUT, DELETE)

- JSON responses
- API versioning
- Documentation

**Files**: `12-Rest_API_Standart/`

## 🚀 Getting Started

### Prerequisites
- **Node.js**: Version 14 or higher
- **npm**: Comes with Node.js
- **Code Editor**: VS Code recommended
- **Basic Programming Knowledge**: Helpful but not required

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ernakkc/javascript-roadmap.git
   cd javascript-roadmap
   ```

2. **Navigate to any module**:
   ```bash
   cd 1-Temel\ Mantık
   ```

3. **Run JavaScript files**:
   ```bash
   node filename.js
   ```

### Setting up Node.js Projects

For modules with package.json:
```bash
cd 10-Express.js
npm install
npm start
```

## 📖 How to Use This Roadmap

### Learning Path

1. **Sequential Learning**: Follow modules in order (1→12)
2. **Practice**: Complete exercises in each module
3. **Projects**: Build mini-projects to reinforce concepts
